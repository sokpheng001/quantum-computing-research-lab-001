# Magic state cultivation: the paper's code and circuits (third-party, unchanged)

This folder is an unmodified copy of the data and code archive of:

> C. Gidney, N. Shutty, C. Jones, *Magic state cultivation: growing T states as cheap as CNOT gates*,
> arXiv:2409.17595 (2024). Archive: Zenodo, DOI [10.5281/zenodo.13777072](https://doi.org/10.5281/zenodo.13777072).

| Path | What it is |
|---|---|
| `code/` | the authors' code; see `code/README.md`. Licence: Apache 2.0, in `code/LICENSE` |
| `circuits/` | the authors' noisy circuits (`.stim`) for every figure of the paper |
| `stats.csv` | the authors' collected statistics |

Our own code that uses it is in the parent folder (`cultivation_plugin.py`). Nothing here was edited.
